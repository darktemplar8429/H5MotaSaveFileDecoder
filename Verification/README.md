# Verification

Run on Windows with .NET 9 SDK:

    dotnet run --project Verification/Verification.csproj -c Release

The 96 checks cover known LZString vectors, JSON/file round trips, output naming
and folder reuse, overwrite protection, integer precision, WinForms construction,
optional padding/BOM, concurrent conversions, JavaScript-looking text remaining
data, and the 64 MiB decoded length limit. The real Jint/library code is exercised.

fixtures.json retains the 12 synthetic string vectors and 6 synthetic save-shaped
JSON vectors from main. Expected values are fixed, not regenerated by the
implementation under test. No player saves are included.

over-limit.lz.txt encodes A repeated 64 * 1024 * 1024 + 1 times. Its efficient
repeated-run generator was checked against upstream LZString at 8 smaller sizes.
See generate-limit-fixture.cjs (optional Node.js utility). The decoder must
reject it with the existing length-limit error.

Window preview and temporary files are generated under bin/.../test-output
and excluded from version control.
